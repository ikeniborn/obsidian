# Сетевые режимы

Гибкая сетевая архитектура Obsidian Sync Server поддерживает три режима Docker-сети для интеграции с различными окружениями.

## Режимы

### Shared Mode (общая сеть)
- **Сеть**: существующая Docker-сеть (выбирается интерактивно из `docker network ls`)
- **Примеры**: `my_app_network`, `webproxy_default`, `traefik_public`
- **Nginx**: может использовать существующий контейнер Nginx из той же сети
- **Переменные**: `NETWORK_EXTERNAL=true`, `NETWORK_NAME=<existing-network>`
- **Применение**: интеграция с существующей инфраструктурой (например, семейный бюджет на том же сервере)

### Isolated Mode (изолированная сеть)
- **Сеть**: `obsidian_network` (создаётся автоматически)
- **Подсеть**: автовыбор из диапазона 172.24–31.0.0/16 (первая свободная)
- **Nginx**: собственный контейнер `notes-nginx`
- **Переменные**: `NETWORK_EXTERNAL=false`, `NETWORK_NAME=obsidian_network`
- **Применение**: standalone-развёртывание без конфликтов с другими сервисами

### Custom Mode
- Произвольное имя сети, задаётся вручную
- **Переменные**: `NETWORK_MODE=custom`, `NETWORK_NAME=<custom-name>`

## Конфигурация в .env

```bash
NETWORK_MODE=shared|isolated|custom
NETWORK_NAME=<имя_docker_сети>
NETWORK_EXTERNAL=true|false
NETWORK_SUBNET=172.25.0.0/16   # только для isolated
```

## Автоопределение

`network-manager.sh` автоматически определяет режим:
- При отсутствии пользовательских Docker-сетей → isolated
- При наличии существующих сетей → предлагает список для выбора в `setup.sh`

## Функции network-manager.sh

| Функция | Назначение |
|---------|-----------|
| `detect_mode` | Автоопределение режима (shared/isolated) |
| `list_networks` | Список доступных Docker-сетей |
| `prompt_network_selection` | Интерактивный выбор сети |
| `find_free_subnet` | Поиск свободной подсети 172.24–31.x.x/16 |
| `validate_subnet` | Проверка доступности подсети |
| `create_network` | Создание Docker-сети |
| `validate_connectivity` | Тест связности между контейнерами |

## Применение в проекте

Выбор сети производится в `setup.sh` (интерактивно). Результат сохраняется в `/opt/notes/.env`. Docker Compose файлы читают переменные `NETWORK_NAME`, `NETWORK_EXTERNAL`.
